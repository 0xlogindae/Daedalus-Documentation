Introduction

FRC Programming tells the robot what to do given the controls of the driver. FRC Programs such as Driverstation or FRC Pathplanner allow us to communicate effective commands. Here's a few of the programs we use and what they do:

FRC Driverstation: Facilitates driving operations and control of the live robot.

WPILIB VSCode: Modified Version of Microsoft's VSCode used for entering code into the robot. (WRITE + DEPLOY)

FRC Pathplanner: Autonomous path creation tool.

RoboRIO Imaging Tool: Tool for imaging the RoboRIO (Main Computer of Robot)

Phoenix Tuner X: Motor Management Software and Swerve Generation Tool.

Please make sure to download all utilies before programming the robot.

Generating Swerve

Please make sure you have Phoenix Tuner X downloaded before starting.

https://apps.microsoft.com/detail/9nvv4pwdw27z

To start, please open Phoenix Tuner X and go to the Devices Tab.

Each Motor connected to CAN (Controller Area Network), a line used to transmit motor commands to every motor on the robot, will be shown here. When programming Swerve we need to know the Name of each motor and it's Unique ID to identify it.
